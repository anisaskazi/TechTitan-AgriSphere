# START HERE — KrishiMitra ONE

For Visual Studio Code: Download **Complete Source**, extract it, and open the directory containing `package.json`. In the terminal, run `npm run dev`, then open http://localhost:4173.

For quick hosting: extract the **Hosting-Ready ZIP**, then upload the folder containing `index.html` to https://app.netlify.com/drop. **Do not use `npm run dev` in Hosting-Ready.**

For Docker: `docker build -t krishimitra-one .` and `docker run -p 8080:80 krishimitra-one`.

For faculty: demonstrate real feature workflows, record changes in multiple meaningful Git commits, run tests/CI and Docker, then take genuine screenshots.

**Important:** The platform is a demonstrator/pilot; it does not have cloud login, verified disease diagnosis, live mandi price ingestion or real order processing. Users must export backups.
