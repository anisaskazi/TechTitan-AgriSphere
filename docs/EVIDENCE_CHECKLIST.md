# ISE-2 DevOps Evidence Checklist

Use real proof only. These are suggested genuine screenshots to capture after actually doing the work.

- [ ] Homepage and mobile layout shown in your actual browser.
- [ ] Farm profile form saved and dashboard updated.
- [ ] Crop search/season/category filtering working.
- [ ] Soil test, task, crop plan, harvest and finances added and visible.
- [ ] Weather shown while internet is available, or honest connection error if blocked.
- [ ] Actual meaningful Git commit history with **five or more changes** (six or more commits recommended).
- [ ] GitHub repository structure and active workflow configuration visible.
- [ ] `npm test` successful in terminal.
- [ ] `npm run build` successful in terminal.
- [ ] GitHub Actions `test-and-build` run marked as passed after a real push.
- [ ] Docker `docker compose up --build -d` succeeds locally (if Docker available).
- [ ] Running container and website at `localhost:8080` photographed as proof.
- [ ] README includes real screenshot paths and explains exactly what is functional.
- [ ] Public demo URL works on both smartphone and laptop after actual deployment.
- [ ] Clear MVP limitations explained in your demonstration.

**Rubric:** project functionality 3, DevOps 3, repository 2, documentation 2 = 10. No model can guarantee marks awarded by faculty.
